# Card D4 — AZUVER 2026

Página estática, com mapa fixo ao fundo, escudo D4 e cinco botões que expandem e recolhem seus próprios links. Sem instalação ou compilação.

## Visualizar

Abra `index.html` em um navegador. Mantenha os arquivos e a pasta `assets` juntos.

## Publicar no GitHub Pages

No repositório, abra **Settings → Pages**. Em **Build and deployment**, escolha **Deploy from a branch**, selecione **main** e **/ (root)**, e salve. O GitHub mostrará o endereço após concluir a publicação.

## Atualizar os links

Edite os destinos em `links.js`. O PNG de **Quem faz o que** está pendente, conforme combinado. Quando estiver pronto, insira seu link do Drive em `equipe` ou coloque o PNG em `assets` e use um caminho relativo.

**Imagens-Base** aponta para a subpasta criada dentro de **17xx D-4**. Ela está vazia e pronta para receber imagens.

Os links dos manuais usam a Biblioteca do próprio exercício. **Regras do jogo** aponta para **Regras do Jogo e Fatores de Planejamento 2026-1.pdf**, da pasta **FAC_CEL MAURÍCIO**.

O site contém links, sem copiar os documentos do Drive. O acesso aos documentos continua seguindo suas permissões no Drive.
